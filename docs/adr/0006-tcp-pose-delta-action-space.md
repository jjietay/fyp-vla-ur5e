# Architecture B acts in TCP pose deltas: seven numbers, base frame translation, rotation delta, absolute gripper

Decided 31 Aug 2026, because A's skills command TCP poses and the comparison is unfair if B solves a different problem; the controller's IK then supplies the kinematics, and `WorkspaceEnvelope` can check every action directly. The state stores rotation as the first two columns of the rotation matrix (10 numbers in all), decided 23 Sep 2026: the down pose has a rotation of pi, where both the rotation vector and Euler roll flip sign for the same pose, and the real arm showed it. Action deltas stay Euler, since a small delta is far from any wrap point. B's per-step limit is derived as `workspace.max_speed * robot.servo.time`, so both architectures share one speed ceiling.
